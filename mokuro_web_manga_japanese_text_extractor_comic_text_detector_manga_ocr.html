Open-Source GitHub Selection: Mokuro + Manga OCR

Why this pipeline is the gold standard for Japanese manga text extraction

Selected Winner: kha-white/mokuro (comic-text-detector + manga-ocr)

Unlike standard OCR engines that fail on vertical Japanese typesetting, furigana ruby glosses, and stylized speech-bubble fonts, manga-ocr (2.8k stars, Apache-2.0) uses a Vision Encoder-Decoder (DeiT ViT + Japanese char-BERT trained on Manga109-s) that reads entire multi-line speech bubbles in a single pass. Paired with comic-text-detector (391 stars, GPL-3.0) as orchestrated by mokuro (1.8k stars, GPL-3.0), it extracts full pages in right-to-left manga reading order.

GitHub Project Stars / License Fit for Manga Text Extraction
kha-white/mokuro + manga-ocr 1.8k & 2.8k ★ · GPL-3.0 / Apache-2.0 Chosen architecture. Highest Japanese bubble accuracy (vertical/horizontal + furigana) and runs directly in-browser via quantized ONNX (~117 MB).
zyddnys/manga-image-translator 10.3k ★ · GPL-3.0 Heavy (~15 GB Docker) end-to-end LaMa image inpainting & typesetting suite; overkill when you just want clean Japanese text extraction.
dmMaze/BallonsTranslator 5.0k ★ · GPL-3.0 Desktop Qt translation/lettering editor (uses manga-ocr + comic-text-detector under the hood, not a lightweight web extractor).
naptha/tesseract.js WASM v5.1.1 · Apache-2.0 Included in the dropdown (~15 MB) as a fast-download fallback, though less accurate on stylized manga fonts and furigana.
